# Code of Conduct

## Purpose

This document sets the ground rules for anyone who participates in the Uncage project. The goal is simple: keep things respectful and productive so everyone can contribute without hassle.

## Expected Behavior

- Be respectful in all interactions, whether in issues, pull requests, or discussions.
- Give constructive feedback. Criticize ideas, not people.
- Accept that others may have different opinions or approaches.
- If you disagree with someone, explain your reasoning calmly.
- Help newcomers. Everyone starts somewhere.

## Unacceptable Behavior

- Personal attacks, insults, or derogatory comments.
- Harassment of any kind, public or private.
- Publishing someone else's private information without their permission.
- Trolling, spam, or deliberately derailing conversations.
- Any conduct that would be considered inappropriate in a professional setting.

## Scope

This code of conduct applies to all project spaces, including the GitHub repository, issues, pull requests, discussions, and any other channel used for project communication.

## Reporting

If someone violates this code of conduct, please open an issue or contact the maintainer directly. All reports will be reviewed and handled with discretion.

## Enforcement

Maintainers have the right to remove, edit, or reject comments, commits, code, issues, and other contributions that violate this code of conduct. Repeat or severe violations may result in a temporary or permanent ban from the project.

## Attribution

This code of conduct is adapted from general open-source community standards. It is not based on any single template.
