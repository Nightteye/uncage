How to use Uncage

Everything you need to get a clean static export.

1. Basic export

  1. Paste the full URL of the site you want to clone (e.g. https://example.com).
  2. Optionally name your output folder — it defaults to the hostname.
  3. Click Start Export and watch the terminal log below.
  4. When it's done, your files are in output/<folder>/.

2. Preview your clone

Open a terminal and run:

cd output/<folder> && npm run preview

This starts a local server so you can see the cloned site in your browser.

3. Fine-tuning options

  • Max pages — Cap how many pages to crawl (default: 50).
  • Timeout — How long to wait for each page (default: 30s).
  • Max link depth — 0 = just the seed page.
  • Headless — Turn off to watch the browser crawl live.
  • Respect robots.txt — On by default.
  • Safe mode — Disables JS. Faster, can't render SPAs.
  • Skip CSS purge — Keeps all classes if dynamic styles look broken.
Tip: If an export looks broken, try enabling Skip CSS purge. PurgeCSS can strip dynamically-applied classes.
Remember: Only clone sites you own or have permission to capture.
