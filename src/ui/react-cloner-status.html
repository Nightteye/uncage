React export is paused.

The React TSX/JSX cloner is paused indefinitely while the static HTML pipeline receives the reliability work it needs. There is no confirmed date for its return.

⏸

Why it's paused

The React exporter had too many reliability issues to ship confidently. Framer and Webflow sites use complex runtime JavaScript, Shadow DOM, and dynamic class injection that the HTML-to-JSX AST compiler couldn't handle consistently. Rather than publish broken exports, the decision was made to focus entirely on the static HTML pipeline first.

Key issues that remain:

  • Inline styles parsed incorrectly for complex CSS functions (calc(), clamp(), nested url())
  • SVG attribute camelCasing conflicts with data-* and aria-* attributes
  • Component naming collisions on sites with similar route slugs
  • Relative link resolution breaks in deeply nested React Router layouts
  • Runtime Framer motion scripts not being injected into the Vite scaffold
✓

What works right now

Static HTML export is the fully supported path. It produces a standalone folder of HTML, CSS, JavaScript, images, fonts, and media that you can open directly in a browser or deploy to any static host. It handles:

  • Multi-page crawling with robots.txt and sitemap awareness
  • Full JavaScript-rendered page capture via Playwright
  • Shadow DOM serialization into declarative shadow templates
  • PurgeCSS and image optimization for smaller output
  • Asset URL rewriting for complete offline portability

Roadmap

Now — Static export reliability

Improving crawl coverage, asset fidelity, and edge-case handling for non-Framer sites (Next.js, Vite, plain HTML).

Next — Output quality

Better CSS preservation, responsive media handling, and font subsetting in static exports.

Later — React export revival

Revisiting the JSX compiler with lessons learned from the static pipeline. No timeline committed.

⑂

Want to help bring it back?

The React cloner code is still in the repository under src/parser.ts, src/assembler.ts, and src/formats/react-*.ts. It's dormant but not deleted. If you want to tackle any of the issues above, pull requests are welcome — they're the fastest way to get React export back.

File an issue or PR at github.com/Nightteye/uncage.
