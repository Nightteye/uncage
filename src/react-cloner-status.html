Project status

The React cloner is paused.

The React cloner is paused indefinitely. It needs more work before it is reliable enough to support again, and I do not have a definite release date for its return.

Ⅱ

Why it is paused

There are still many bugs in the React export. Rather than publish an export that may be hard to use or fix, I am focusing Uncage on the static HTML, CSS, and JavaScript exporter for now.

Want to help?

The React cloner code is still available in this repository. If you would like to work on it, you can try to fix an issue and open a pull request. Contributions are welcome, and they can help bring the React exporter back in the future.
